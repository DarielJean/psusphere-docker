# PSUSphere# PSUSphere

## Project Description

PSUSphere is a Django-based student organization management system. 
It allows administrators to manage colleges, academic programs, students, 
student organizations, and organization memberships through the Django Admin interface.

## Features

- Manage Colleges
- Manage Academic Programs
- Manage Students
- Manage Student Organizations
- Manage Organization Memberships
- Search students and organizations
- Filter colleges, programs, and organizations
- View student organization membership information
- Generate initial data using Faker
- Django Admin interface for managing data

## Technologies Used

- Python
- Django
- SQLite
- Faker
- Git
- GitHub
